# 安康守护｜健康安全管理网站

安康守护是一款面向日常健康记录与安全提醒的 Web 应用。普通用户可以记录运动、饮食、睡眠和视力情况，制定计划、参加健康挑战，并查看个人趋势；管理员通过独立页面查看汇总数据。游客可浏览页面和检索健康知识，但不会看到其他用户的记录，也不能保存个人数据。

> 本项目提供日常健康信息与记录工具，不提供疾病诊断、处方或急救服务。AI 生成内容不能替代专业医护人员的意见。

## 功能

- **个人记录**：个人档案、运动、饮食、睡眠和视力记录；支持修改与删除。
- **计划与挑战**：锻炼计划、饮食计划、早睡、控糖和饮水打卡。
- **趋势与知识**：安全健康分析、健康知识检索，以及可选的 AI 习惯洞察和问诊对话。
- **管理员后台**：独立登录入口，查看用户记录和挑战的汇总统计。
- **天气提示**：展示城市天气、温度预报和简要穿衣建议。

## 技术栈

Node.js 原生 HTTP 服务，HTML、CSS、JavaScript 前端；支持 MySQL 8，未配置 MySQL 时使用本地 JSON 存储。AI 功能由服务端调用另行配置的兼容接口；天气数据由服务端请求 Open-Meteo。

## 项目结构

```text
安全/        网站前端、管理员后台、服务端接口与测试
账号/public/  登录界面资源，由安全目录中的服务端提供
```

请保持 `安全` 和 `账号` 两个目录同级；从 `安全` 目录启动网站。

## 本地运行

需要 Node.js 18 或更高版本。在仓库根目录打开 PowerShell，依次执行：

```powershell
cd .\安全
npm ci
node .\scripts\init-demo-user.cjs
npm start
```

打开 <http://localhost:3000/>。初始化脚本仅用于**不配置 MySQL 的本地演示**：首次运行时生成普通用户和管理员账号，随机密码只在本机终端显示；如果账号文件已经存在，脚本不会覆盖。按 `Ctrl+C` 可停止服务。

### 使用 MySQL

先创建空数据库，并在启动网站的同一个终端设置 `MYSQL_HOST`、`MYSQL_PORT`、`MYSQL_USER`、`MYSQL_PASSWORD`、`MYSQL_DATABASE`。服务会创建所需表，但不会自动创建登录账号；账号需要通过你自己的部署或迁移流程导入。不要把数据库连接信息提交到仓库。

### 启用 AI

在服务端环境变量中设置 `HEALTH_AI_API_KEY`、`HEALTH_AI_MODEL` 和 `HEALTH_AI_BASE_URL`。字段示例见 [`安全/.env.example`](安全/.env.example)；程序**不会自动加载**该文件。未配置时，AI 问诊和洞察不可用，其他本地记录功能仍可使用。

## 运行测试

```powershell
cd .\安全
node --test test/*.test.js
```

## 隐私与部署

仓库不包含用户记录、账号数据、数据库或 API 密钥。请勿提交 `data/`、`.env`、数据库备份和个人信息。服务默认只监听 `127.0.0.1`，**这份代码不能直接作为公网生产服务使用**；对外部署前需完善 HTTPS、安全 Cookie、稳定的会话密钥、账号管理、备份与安全审查。

实现细节、资料来源和功能边界见 [`安全/README.md`](安全/README.md)。
